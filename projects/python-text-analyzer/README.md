# Python Text Analyzer

A beginner-friendly Python project that analyzes text and displays the most frequent words.

## Features

- Count total words
- Count unique words
- Remove punctuation
- Ignore stopwords
- Show top 10 frequent words

## Technologies Used

- Python
- Dictionaries
- String Processing
- Loops
- Sorting

## Project Structure

```bash
python-text-analyzer/
│
├── main.py
├── README.md
├── sample_input.txt
└── requirements.txt
└── output.txt

```

## How to Run

Run the following command:

```bash
python main.py
```

Then enter your text input in the terminal.
